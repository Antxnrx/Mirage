How it works

Built to drop into any Zcash wallet.

⌁

Boundary index

Reads every block from the light-wallet server and records each public shield and deshield across Sapling, Orchard and Ironwood.

∑

mirage-core

The scoring and exit planner, open source and on npm. The same code runs in the browser and on the server.

⇢

Safe-exit engine

Splits with one shielded send, schedules pieces, re-checks each one, and never pays twice after a restart.

browser → scores locally ⟶ Mirage server → index + exit scheduler ⟶ wallet engine (private network) ⟶ Zcash testnet NU7 · Ironwood
