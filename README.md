# Mirage

**Stay private when you leave the shielded pool.**

Mirage keeps Zcash users shielded first: it checks how traceable a withdrawal would be before you send it, pays shielded when it can, and prepares funds inside the shielded pool when an exit is unavoidable.

Built at Free Society Hack (Mumbai, 4 Nov 2026), Privacy track. Zcash testnet only.

> Work in progress. Product and design docs live on the [`docs`](../../tree/docs/docs) branch.
