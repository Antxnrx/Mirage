# Mirage

**Stay private when you leave the shielded pool.**

Mirage checks how traceable a Zcash withdrawal is *before* you send it, and plans a safer exit when it isn't.

Built at Free Society Hack (Mumbai, 4 Nov 2026), Privacy track. Zcash testnet only.

> Work in progress. Product and design docs live on the [`docs`](../../tree/docs/docs) branch.
